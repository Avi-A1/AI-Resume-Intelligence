# AI Resume Intelligence

An AI-powered resume analysis application that evaluates resumes,
extracts skills, calculates ATS compatibility, and provides career
readiness insights.

## 🚀 Features

- ATS Resume Score
- Resume Parsing
- Skill Extraction
- Career Readiness Analysis
- Job Role Recommendations
- User Authentication
- Resume History

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- SQLite
- NLP
- TF-IDF
- Logistic Regression

## 🧠 How It Works

1. User uploads their resume
2. The system extracts the resume text
3. Skills and keywords are identified
4. TF-IDF analyzes important terms
5. The system generates an ATS score
6. Career insights are displayed
